Save The Watermelon

Description
It is a terminal based word guessing game written in python. The program randomly selects a secret word and the player has to try and guess it by choosing random letters before runing out of slices

Game rules
1. The player starts with 6 slices
2. the player inputs one letter at a time
3. reveals the letter in the secret word if guess was correct
4. deducts one slice if guess is wrong
5. duplicte guesses or other invalid ones dont lose slices
6. the player wins by revealing all letters
7. the player loses by losing all slices
8. The player can chose to replay 

Instructions for running program
1. have python 3.x installed on your computer
2. open terminal, cmd, or an ide
3. paste the code from game.py and run the game

Features implemented
1. displays the secret word with underscores matching length of word
2. has input rejecting for invalid inputs
3. is not case sensitive so you can do capital or lowercase and will be corrected
4. prints updates of word and slice amount
5. has win loss detection by checking amount of revealed letters or slices
6. has a replay option to play again after you win or lose
