Save The Watermelon

Description
It is a terminal based word guessing game written in python. The program randomly selects a secret word and the player has to try and guess it by choosing random letters before runing out of slices

Game rules
1. The player starts with 6 slices
2. the player inputs one letter at a time
3. reveals the letter in the secret word if guess was correct
4. deducts one slice if guess is wrong
5. duplicte guesses or other invalid ones dont lose slices
6. the player wins by revealing all letters
7. the player loses by losing all slices
8. The player can chose to replay
